# J.A.R.V.I.S. — FBI CASE ANALYST

Мобильный стартовый проект для игрового делопроизводства Arizona RolePlay.

## Что реализовано

- Адаптивный интерфейс Mobile First на русском языке.
- Приветствие J.A.R.V.I.S.: «Добро пожаловать, сэр. Что у нас сегодня на рассмотрении?»
- Главная панель и статистика.
- Вставка текста CASEFILE и загрузка нескольких видео.
- Серверный вызов модели через OpenAI API.
- Извлечение выборочных кадров из видео через FFmpeg.
- Попытка транскрибации аудио.
- Сохранение дел и нормативных документов в JSON.
- Импорт доступных публичных HTML/TXT нормативных страниц по URL.
- Формирование BBCode-проекта заключения.
- Архив, поиск и утверждение статуса.
- PWA manifest.

## Требования

- Node.js 20+
- FFmpeg, доступный в PATH (для обработки видео)
- API-ключ OpenAI с доступом к выбранной модели

## Запуск

1. Распакуйте архив.
2. В папке проекта выполните `npm install`.
3. Скопируйте `.env.example` в `.env`.
4. Впишите API-ключ в `OPENAI_API_KEY`.
5. При необходимости измените `OPENAI_MODEL`.
6. Установите FFmpeg и убедитесь, что команда `ffmpeg -version` работает.
7. Выполните `npm start`.
8. Откройте `http://localhost:3000`.

## Важно

Это рабочая стартовая версия, но не готовая к публичному развёртыванию государственная система. Перед реальным использованием добавьте авторизацию и роли, HTTPS, ограничение запросов, антивирусную проверку загрузок, резервное копирование, защищённое хранилище файлов, контроль доступа к делам и аудит действий.

Видео анализируется по ограниченному числу выборочных кадров с шагом 10 секунд; это не покадровое изучение всей записи. Аудиотранскрибация может не сработать для больших файлов или неподдерживаемых контейнеров. Необходимо явно проверять полноту и качество доказательств.

Импорт ссылок поддерживает доступные публичные HTML и TXT. Форумы с авторизацией, защитой от ботов или динамической загрузкой могут не читаться. PDF и полноценный поиск по всему интернету в этой версии не реализованы. Добавленные документы помечаются как требующие проверки актуальности: приложение не может само гарантировать, что редакция закона действующая.

Данные сохраняются в JSON-файлах на сервере без шифрования. Не размещайте проект публично с реальными персональными данными до реализации защиты.
